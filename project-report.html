نظرة عامة على المشروع

برنامج الأنشطة الصفية هو منصة تعليمية تفاعلية متكاملة، مصممة لتعزيز التفاعل والمشاركة بين الطلاب والمعلمين داخل الصف، من خلال مجموعة متنوعة من الألعاب والأنشطة التعليمية الحديثة.

🎯 الهدف الرئيسي: تحويل البيئة التعليمية التقليدية إلى بيئة تفاعلية محفزة للتعلم من خلال الألعاب والأنشطة الذكية.

المميزات الرئيسية

🔗 ربط مباشر بالبيانات

ربط مباشر ببيانات الطلاب (الاسم والصف) مع كل نشاط، مما يتيح للمعلم تنفيذ أي نشاط في أي وقت دون الحاجة لإعادة إدخال البيانات.

📱 تجربة متجاوبة

تصميم متجاوب بالكامل يعمل على جميع الأجهزة (الكمبيوتر، الجهاز اللوحي، الهاتف الذكي) مع واجهة سهلة الاستخدام.

🎮 ألعاب تفاعلية متنوعة

مجموعة واسعة من الألعاب التعليمية التي تجمع بين المتعة والتعلم، مع إمكانية التخصيص حسب المنهج.

📊 نظام إدارة الغياب

نظام متقدم لتسجيل ومتابعة غياب الطلاب مع إمكانية التصدير والمشاركة والتحليل.

🔊 تأثيرات صوتية

مكتبة شاملة من الأصوات والتأثيرات الصوتية لتعزيز التجربة التفاعلية.

⚙️ سهولة التخصيص

إمكانية تخصيص البرنامج بسهولة ليناسب احتياجات كل مدرسة مع إعدادات مرنة.

مملكة الحكمة

البنية التقنية

التقنيات المستخدمة:

  • اللغات: HTML5, CSS3, JavaScript (ES6+)
  • التصميم: CSS Grid, Flexbox, Responsive Design
  • الخطوط: Cairo Font (مدعوم للعربية)
  • الأيقونات: Material Icons, Font Awesome
  • البيانات: JSON Files لسهولة التخصيص
  • التوافق: جميع المتصفحات الحديثة

هيكل المجلدات:

  • activities/: جميع ملفات الأنشطة والألعاب (17 نشاط)
  • assets/css/: ملفات التنسيق والأنماط
  • assets/js/: ملفات الجافا سكريبت التفاعلية
  • assets/media/: الوسائط المتعددة (صور وأصوات)
  • config/: ملفات التكوين للمدرسة والإعدادات
  • data/: بيانات الطلاب والجداول الزمنية

المتطلبات والتشغيل

متطلبات النظام:

  • يعمل البرنامج كتطبيق ويب (Web App) بالكامل عبر المتصفح
  • يتطلب اتصالاً بالإنترنت أثناء الاستخدام
  • يفضل استخدام متصفح حديث (Chrome, Edge, Firefox, Safari)
  • لا يحتاج إلى تثبيت أو تحميل برامج إضافية

📋 البيانات المطلوبة للتخصيص:

  • 🏫 بيانات المدرسة: معلومات المدرسة والإعدادات الأساسية
  • 📅 أوقات الحصص: تحديد الجدول الزمني للحصص
  • 👥 قائمة أسماء الطلاب: حسب الفصول الدراسية
  • 🖼️ الشعار الرسمي للمدرسة
  • 🔗 رابط SheetDB (اختياري لتفعيل ميزة تسجيل الغياب)
